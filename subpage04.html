Activity 01

Wear Now

창업기획서 대외활동 'Wear Now'

날씨와 상황에 맞는 의류 선택을 돕는 서비스 아이디어

문제 인식

날씨 변화와 개인 일정에 따라 옷차림을 고민하는 사용자를 위해, 지금 입기 좋은 스타일을 추천하는 서비스 방향을 설정했습니다.

기획 방향

사용자의 현재 상황과 날씨 정보를 기반으로 의류 선택을 도와주는 서비스를 제안하고, 창업기획서 형식에 맞춰 시장성과 기능 흐름을 정리했습니다.

참여 과정

팀 프로젝트 형태로 아이디어를 정리하고, 서비스명과 주요 기능, 기대효과를 발표 자료로 구성하며 기획 흐름을 다듬었습니다.

기대효과

단순한 날씨 확인을 넘어 실제 행동으로 이어지는 옷차림 추천 경험을 제공해 사용자의 일상 선택 부담을 줄이는 것을 목표로 했습니다.

Activity 02

Table 08

모바일 주문 서비스 기획 'Table 08'

테이블 번호 기반의 빠른 주문과 주문 확인 흐름

서비스 콘셉트

매장에서 사용자가 테이블 번호를 기준으로 메뉴를 확인하고, 장바구니에 담아 빠르게 주문할 수 있는 모바일 주문 서비스를 기획했습니다.

화면 흐름

카카오 로그인, 메뉴 검색과 카테고리 선택, 장바구니 확인, 주문 완료 화면까지 사용자가 자연스럽게 이동할 수 있도록 화면 순서를 구성했습니다.

사용자 경험

하단 내비게이션과 명확한 버튼 색상을 사용해 현재 위치와 다음 행동을 쉽게 파악할 수 있도록 정리했습니다.

활동 결과

식당 주문 과정을 모바일 환경에 맞게 단순화하면서, 메뉴 선택부터 주문 완료까지의 주요 화면을 시각적으로 구현했습니다.
